Admin User Management

Admin commands are restricted to user IDs in ADMIN_USER_IDS. To enable admin commands, add your Bale numeric ID to ADMIN_USER_IDS in .env.

Edit ADMIN_USER_IDS in .env and restart the bot to apply changes.

How to Find Your Bale User ID

  1. Send /start to the bot once
  2. Your numeric ID will appear in the bot's terminal log
  3. Or check data/bot.db (users table) after interacting
  4. Add it to ADMIN_USER_IDS in .env (comma-separated)
  5. Restart the bot to enable admin commands
